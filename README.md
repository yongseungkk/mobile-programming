# LLM 에이전트 기반 요리 도우미 앱
> 보유한 식재료와 취향에 맞춰 메뉴를 추천하고, 조리 과정을 안내하는 요리 도우미

## 프로젝트 소개
요리에 익숙하지 않은 사람들이 가지고 있는 식재료로
무엇을 만들지 결정하고 직접 요리할 수 있도록 돕는 앱입니다.

사용자의 식재료, 취향, 조리 가능 시간 등을 바탕으로
LLM 에이전트가 메뉴를 추천하고 단계별 조리 방법을 안내합니다.

## 주요 사용자
- 요리 경험이 적어 간단한 조리 안내가 필요한 자취생
- 보유한 식재료를 활용해 식사를 준비하려는 사용자

## 해결하려는 문제
- 식재료는 있지만 어떤 요리를 만들 수 있는지 판단하기 어렵다.
- 레시피를 찾아도 재료나 조리 시간이 자신의 상황과 맞지 않는다.
- 유통기한이 얼마 남지 않은 음식들을 까먹다가 결국에는 버리게 된다

## 주요 기능 — (기획 중)
- 설문조사 (개인 취향, 상태)
- 보유 식재료 입력 및 관리
- 취향과 조리 시간을 반영한 메뉴 추천
- 필요한 재료와 단계별 조리 방법 안내
- 커뮤니티

## LLM 에이전트의 역할
사용자의 자연어 요청에서 식재료와 조리 조건을 파악하고,
대화를 통해 조건을 조정하며 요리 과정을 돕습니다.
